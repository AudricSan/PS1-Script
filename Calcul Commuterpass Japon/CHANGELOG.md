# Changelog pour les scripts Commuterpass

Toutes les modifications notables apportées à ces scripts seront documentées dans ce fichier.

## [1.5.1] - 2025-01-06

### Ajouté
- **comuterpass1.5.sh** :
  - Ajout du calcul pour un trajet composé (somme de deux trajets).
  - Option pour afficher les coûts totaux sans abonnement pour le trajet composé.

## [1.5.0] - 2025-01-05

### Ajouté
- **comuterpass1.5.py** :
  - Support pour plusieurs trajets (Trajet 1, Trajet 2, et Trajet composé).
  - Comparaison des coûts pour chaque trajet et pour un trajet combiné.
  - Option pour afficher les économies potentielles pour un trajet composé.

## [1.0.0] - 2024-12-31

### Ajouté
- **Commuterpass1.0.py** :
  - Calcul des coûts sans abonnement et avec abonnements (1 mois, 3 mois, 6 mois).
  - Comparaison des économies potentielles et des seuils de rentabilité.
- **Commuterpass1.0.sh** :
  - Version Bash avec les mêmes fonctionnalités que `Commuterpass1.0.py`.
